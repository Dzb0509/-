# 食刻 AI · 你的 AI 营养分析师

> 全国高校 AI Web 开发挑战赛参赛作品 · 推荐方向 6「AI 健康与生活服务」
> 在线体验：见作品提交链接

**食刻 AI** 主打「每日餐食推荐」：从人群出发，为个人与家庭生成一整份营养均衡的每日食谱，并给出可解释的推荐理由。识餐、点评、周报构成完整的饮食管理闭环。

## ✨ 核心功能

### 🎯 智能推荐（主打）
- **两级人群定位**：成年人 / 老年人 / 儿童青少年 / 婴幼儿 / 孕产期 5 大人群组，细分 13 种需求（减脂、增肌、控糖、高血压、糖尿病、高血脂、辅食期、孕期、哺乳期…）
- **一整份餐桌套餐**：家庭模式按「一荤一素一汤一主食」组成整桌菜，AI 统筹全家营养交集（有孕妇保叶酸、有老人低盐软烂、有孩子高营养密度），早餐 3 道、午晚餐各 4 道、零跨餐重复
- **AI 自定义偏好**：口味 / 需求 / 忌口自由填写，GLM 生成专属方案，推荐自动避开忌口
- **🌐 AI 联网搜菜谱**：按家庭构成联网搜索贴合的菜谱灵感，GLM 融合为完整可做的菜谱（食材 + 步骤 + 适合理由）进入推荐
- **🏠 上传家传菜谱**：录入家里自己的菜谱（食材 + 做法），参与全家推荐并优先入选
- **可解释推荐**：每餐给出推荐理由，说明照顾了哪位成员、为什么这样搭配
- **超详细做法**：每道菜带食材清单、分步骤做法与热量营养数据，点卡片开详情弹窗

### 📷 识餐与记录（辅助闭环）
- **拍照识餐**：GLM-4V 视觉识别菜品与份量，识别结果可修正后一键记录
- **口味画像自动学习**：根据历史饮食记录沉淀口味偏好，反哺推荐
- **昨日 → 今日**：根据昨天吃了什么推荐今天/明天，避免重复
- **📊 AI 周报**：热量趋势图 + AI 总结点评（流式输出）
- **🧑‍⚕️ AI 营养师对话**：Function Calling Agent，工具调用过程可视化

### 🖼 真实菜品图片（0 元方案）
- **536 张图片双缓存**：本地磁盘缓存毫秒级返回，浏览器 ETag 协商缓存
- **必应图库候选轮换**：每道菜可「换一张」，从必应搜索真实菜品图，自动裁边去水印；首次约 1s，再点 38ms
- **AI 悬浮小助手**、首页图文轮播、地方特色菜分区

## 🛠 技术架构

```
前端  Vue 3 + Nuxt 3 (SPA) + TypeScript + Tailwind CSS + Pinia + Element Plus + ECharts
后端  Nuxt Server Routes（同仓一体，作为 AI 接入层）
模型  智谱 GLM-4-Flash（推荐/对话/点评/周报）· GLM-4V-Flash（识餐）
      智谱 Web Search（联网菜谱）· embedding-3（RAG 向量检索）
```

### 服务端 API

| 路由 | 说明 |
|---|---|
| `POST /api/recommend` | **混合推荐引擎**：规则打分采样出候选 → GLM 择优并生成整桌套餐与理由；`fast=true` 时跳过 GLM 由规则引擎 5ms 直出 |
| `POST /api/customize` | AI 自定义偏好 → 生成个人专属方案 |
| `GET  /api/dish-image` | 菜品图：本地缓存 → 必应候选轮换（`alt=N`）→ AI 生成兜底 |
| `POST /api/vision` | GLM-4V 拍照识餐（JSON Schema 约束输出） |
| `POST /api/chat` | 营养师 Agent（Function Calling + SSE 流式） |
| `POST /api/comment` | RAG 检索 + 流式营养点评 |
| `POST /api/report` | AI 周报生成 |
| `GET  /api/dishes` | 菜库数据（529 道菜，含营养数据与做法） |

### 工程亮点

1. **混合推荐架构**：AI 深度生成（个性化统筹）+ 本地规则引擎（毫秒级换一批）双轨并行——首屏质量与交互速度兼得，换一换实测 **5ms**
2. **性能优化**：家庭三餐串行改并行（40~60s → **28.5s**）、推荐结果本地缓存秒开 + 后台静默刷新、请求序号防竞态、防抖
3. **0 元图片方案**：AI 生成图片成本高且免费模型质量不稳，改用「必应真实图 + 本地缓存 + 候选轮换」，536 张图预热后全部毫秒级
4. **RAG 营养知识库**：点评前检索《中国食物成分表》《膳食指南》，杜绝营养数据幻觉；embedding 超时自动降级
5. **安全**：API Key 仅存服务端环境变量（`start-prod.mjs` 启动注入），绝不打包进前端；忌口关键词过滤贯穿推荐全链路
6. **负责任 AI**：非诊断红线、常驻免责声明、低置信度识别提醒用户确认

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（复制 .env.example 为 .env，填入智谱 API Key）
cp .env.example .env

# 3. 启动开发服务
npm run dev
# 访问 http://localhost:3000

# 生产部署
npm run build
node start-prod.mjs
```

> 未配置 API Key 时，AI 能力自动降级为本地规则引擎，可完整体验全部交互流程。
